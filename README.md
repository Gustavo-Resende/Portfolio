# Portfólio - Gustavo Resende

O **Portfólio** é uma plataforma digital imersiva projetada para demonstrar excelência em engenharia de software e arquitetura de sistemas. Utilizando React, Next.js e Tailwind CSS, o sistema apresenta uma interface responsiva focada em performance e design moderno (Dark Theme & Color Blocking), garantindo uma narrativa técnica otimizada e ilustrando com clareza a proficiência técnica na criação de APIs escaláveis e integrações robustas.

## 🚀 Tecnologias Essenciais

- **Framework:** Next.js / React
- **Estilização:** Tailwind CSS (com tema Dark Matte customizado)
- **Animações:** Framer Motion
- **Internacionalização:** Suporte Nativo (PT-BR / EN)
- **Design de Componentes:** Lucide React Icons

## ⚙️ Arquitetura Visual e UX
O design foi fundamentado nas tendências mais modernas de UI/UX, utilizando:
- **Color Blocking Sectioning:** Separação abrupta entre o topo imersivo com *Ambient Glow* e a leitura técnica com fundos escuros absolutos, minimizando a fadiga visual.
- **Glassmorphism:** Efeitos de vidro (desfoque) aplicados de forma cirúrgica na navegação.
- **Micro-interações:** Utilização de `framer-motion` em carrosséis e revelações de conteúdo orientados à rolagem da página.

## 💻 Rodando Localmente

Para iniciar o servidor de desenvolvimento:

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador para ver a aplicação rodando.
